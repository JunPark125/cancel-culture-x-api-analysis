# Synthetic demonstration fixture

`synthetic_posts.json` contains three invented API-shaped post objects with deliberately nonnumeric post and author IDs. All text is marked synthetic. Engagement values and dates are invented solely to exercise transformations; they are not research observations.

`python -m src.demo` attempts one repeated object to demonstrate duplicate suppression, then builds exports and reports using the copied workflow. Nothing in this directory was taken from a real X post.
