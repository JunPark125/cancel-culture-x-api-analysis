# Data availability

Original research data are deliberately absent. Post text, identifiers, simplified exports, labels, raw JSON, and aggregate research tables remain in the untouched research workspace. Their exclusion also applies to private Git hosting.

The [sample fixture](sample/README.md) contains invented records for offline testing. It was written from scratch, not sampled or anonymized from real posts. All runtime subdirectories are ignored by Git. See the [data dictionary](../docs/data_dictionary.md) and [usage guide](../docs/usage.md) for private schemas and input paths.
